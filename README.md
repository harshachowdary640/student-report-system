# Northstar Student Reports

A React and TypeScript student report dashboard built to demonstrate component rendering, `useState`, props, and React Router.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Deploy to Vercel

Run `vercel --prod` from this project directory. The included `vercel.json` supports direct visits to student profile routes.

## Demo features

- Student overview, searchable directory, grade filters, and add-student form
- Student report cards with subject grades and pass/fail results
- React lab examples for counters, forms, calculator, to-do list, props, and routing
- Responsive layout, dark mode, and print-friendly reports

The app uses sample data and keeps changes in client-side React state; it does not connect to a database or authentication service.
